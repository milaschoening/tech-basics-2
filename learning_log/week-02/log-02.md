## Circuit Basics
- Short circuits: never connect + and - directly, as this can damage the board or components
- GND (ground): the circuits common zero-volt reference and return path for current
- Direct current (DC): electric current that flows straight in one direction
- Alternating current (AC): electric current that periodically changes direction
- Series circuit: components are connected along a single path, so the same current flows through each of them
- Parallel circuit: components are connected in seperate branches, they run independently so that a single failure does not effect the entire system
- Voltage (V), Current (I), Resistance (R)
